# AGENTS.md

## Cursor Cloud specific instructions

This repository is a **static marketing website** for Sopjani Tech Sàrl (HVAC company, French language). There is no backend, database, or package manager.

- **Tech stack:** Plain static HTML/CSS/JS. Pages, `css/main.css`, `js/main.js`, and `sitemap.xml`/`robots.txt` are generated by a single Python 3 script, `build_site.py`, which uses only the Python standard library (no `pip install`, no `requirements.txt`/`package.json`).
- **Regenerate the site (build):** `python3 build_site.py` from the repo root. It prints `Site generated successfully.`
  - Note: regenerating updates the `<lastmod>` dates in `sitemap.xml` to today's date, so a clean repo will show a `sitemap.xml` diff after every build. This is expected; revert it (`git checkout sitemap.xml`) if you do not intend to commit a date bump.
  - Running the script also creates a local `__pycache__/` directory (untracked) — ignore it.
- **Run/preview locally:** `python3 -m http.server 8000` from the repo root, then browse `http://localhost:8000/`. Any static file server works; you can also open `index.html` directly.
- **No lint/test tooling exists.** Closest to a build/lint check is `python3 -m py_compile build_site.py` plus running the generator.
- **Contact form:** local-only. `FORM_ENDPOINT` is empty in `build_site.py`, so submitting the contact form shows a local confirmation message ("Merci pour votre message…") and does not send anything. Set `FORM_ENDPOINT` (e.g. a Formspree URL) and regenerate to enable real submissions.
- **Deployment:** GitHub Pages (`CNAME` → `sopjanitech.ch`); generated files are committed directly.
